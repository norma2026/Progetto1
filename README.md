# Progetto1

Questo progetto fa parte delle esercitazioni del corso della scuola **DAXUs**.  
L'obiettivo è costruire il mio **portfolio personale**, partendo da zero e imparando a usare Git, GitHub e Visual Studio Code in modo corretto e organizzato.

## Contenuti

Il progetto includerà:

- Script Python di esempio
- Struttura modulare con cartelle dedicate
- Esercizi pratici di programmazione
- Documentazione chiara e leggibile

## Obiettivi

- Imparare a gestire un repository Git
- Organizzare il codice in modo professionale
- Preparare una base solida per il portfolio finale
